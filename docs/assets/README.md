# Logo

| File | Use |
|---|---|
| `logo.svg` | Mark on a transparent background (the keyhole is cut out) |
| `logo-badge.svg`, `logo-512.png` | Mark on a dark rounded square, for avatars and app-style icons |
| `logo-wordmark-dark.svg` | Mark and name, for dark backgrounds |
| `logo-wordmark-light.svg` | Mark and name, for light backgrounds |
| `social-preview.png` | 1280×640 image for the repository's social preview (Settings → General → Social preview) |

The mark is a disk with a keyhole that breaks into pixels: the data is encrypted, and destroying the key turns it into noise.

Colors: teal `#2DD4BF` on dark backgrounds, `#0F9488` on light; ink `#E6EDF3` / `#0B1220`.

The name is set in [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) Bold (SIL Open Font License 1.1), converted to outlines so the SVGs need no fonts.
